Books

Books and free Unity e-books worth reading, with the guides in the library that cover the same topics.

Shaders & VFX

  • Unity 6 Shaders and Effects Cookbook

    John P. Doran. You want recipe-style Shader Graph and visual effects examples written for Unity 6.

  • Building Quality Shaders for Unity

    Daniel Ilett. You want a structured path from HLSL shader code to Shader Graph, across the built-in, URP and HDRP pipelines.

  • Beginner's Guide to Unity Shader Graph

    Álvaro Alda. You are new to shaders and want twelve worked Shader Graph effects, from scan lines to water.

  • Create popular shaders and visual effects with the Universal Render Pipeline

    Unity · Free. Toon and outline shaders in Shader Graph, plus X-ray style effects with stencils.

  • Introduction to the Universal Render Pipeline for advanced Unity creators

    Unity · Free. Setting up URP, quality settings, Adaptive Probe Volumes and custom HLSL shaders.

  • The definitive guide to creating advanced visual effects in Unity

    Unity · Free. Building real-time effects with the VFX Graph and its related tools.

  • The Unity Shaders Bible, Second Edition

    Fabrizio Espíndola. You want one book that takes shaders from the basics in Shader Graph and ShaderLab to vertex and fragment work in HLSL, URP lighting and materials, then compute shaders and ray marching.

C# & architecture

  • Unity 6 Game Development with C# Scripting

    Lem Apperson. You want to learn Unity scripting in C# by building complete game projects.

  • Learning C# by Developing Games with Unity 6

    Harrison Ferrone. You are new to C# and want to learn it while building a first-person prototype.

  • Create modular game architecture in Unity with ScriptableObjects

    Unity · Free. Structuring a project with ScriptableObjects, with a companion demo project.

  • Level up your code with design patterns and SOLID

    Unity · Free. SOLID principles and common game patterns such as Factory, Observer, Singleton and Object Pooling, with a sample project.

  • Use a C# style guide for clean and scalable game code

    Unity · Free. Naming, formatting and commenting conventions for a shared Unity codebase.

  • Learning Design Patterns with Unity

    Harrison Ferrone. You want to apply Singleton, Observer, Factory, Visitor, Decorator and other patterns in Unity projects without over-engineering.

  • C# 14 and .NET 10: Modern Cross-Platform Development Fundamentals, Tenth Edition

    Mark J. Price. You want a thorough, regularly updated introduction to C# 14 and .NET 10 fundamentals.

  • C# 12 in a Nutshell: The Definitive Reference

    Joseph Albahari. You want a compact, thorough reference to the C# language and .NET for when you are past the basics.

  • C# in Depth, Fourth Edition

    Jon Skeet. You want a deep look at how C# language features work, including those added in C# 5, 6 and 7.

  • The C# Player's Guide, Fifth Edition

    RB Whitaker. You are new to C# and want a friendly, step-by-step introduction. The fifth edition covers C# 10 and .NET 6.

  • Clean Code: A Handbook of Agile Software Craftsmanship

    Robert C. Martin. You want to write readable, maintainable code: naming, structuring functions and cleaning up bad code. The examples are in Java, but the ideas carry over to C#.

  • Design Patterns: Elements of Reusable Object-Oriented Software

    Erich Gamma, Richard Helm, Ralph Johnson and John Vlissides. You want the original catalogue of 23 object-oriented design patterns, the reference behind most architecture talk.

  • Agile Principles, Patterns, and Practices in C#

    Robert C. Martin and Micah Martin. You want agile design, test-driven development and refactoring shown through case studies, moving from UML models to C# code, with design principles and patterns.

Game programming

  • Game Programming Patterns

    Robert Nystrom · Free. You want the patterns behind game code (state machines, observers, object pools, game loops) explained with clear examples. Free to read online.

  • Game Engine Architecture, Third Edition

    Jason Gregory. You want to understand how a whole engine fits together: memory, rendering, animation, physics, concurrency. Written by a Naughty Dog engineer.

  • Game Coding Complete, Fourth Edition

    Mike McShaffry and David Graham. You want a start-to-finish tour of what goes into shipping a game: architecture, resources, input, audio, AI, debugging.

  • 3D Math Primer for Graphics and Game Development, Second Edition

    Fletcher Dunn and Ian Parberry · Free. You want the vector, matrix and rotation math behind 3D graphics and games, explained for programmers. The full book is free to read online.

Game design

  • The Art of Game Design: A Book of Lenses, Third Edition

    Jesse Schell. You want a framework for thinking about game design: over 100 sets of questions ("lenses") for judging a game from different angles, with examples from classic and modern games.

  • A Theory of Fun for Game Design

    Raph Koster. You want a short, illustrated look at what makes games fun and what players learn from them, updated with newer science and theory in the 10th anniversary edition.

  • Level Up! The Guide to Great Video Game Design, Second Edition

    Scott Rogers. You want a practical guide to designing games: developing ideas, pre-production through post-production, controls, monetization and design documents.

  • Game Design Workshop, Fifth Edition

    Tracy Fullerton. You want to learn game design by doing: exercises on formal, dramatic and dynamic systems, prototyping and playtesting, with no programming or art required.

  • A Playful Production Process: For Game Designers (and Everyone)

    Richard Lemarchand. You want a process for taking a digital game from idea through preproduction, production and post-production, with playtesting and iteration, while avoiding crunch.

  • Blood, Sweat, and Pixels: The Triumphant, Turbulent Stories Behind How Video Games Are Made

    Jason Schreier. You want true stories of how games get made, from big studios to small indie teams, including the setbacks as well as the wins.
