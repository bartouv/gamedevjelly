Repos

Open-source repos worth knowing for Unity, with health checks and the guides that cover them.

Async & reactive

  • UniTask

    You want async/await in Unity without allocations, with PlayerLoop-aware delays and cancellation.

  • R3

    You want Rx-style reactive streams; the successor to UniRx.

  • MessagePipe

    You need an in-process pub/sub or mediator that works with DI containers.

Serialization & data

  • MessagePack-CSharp

    You want compact, fast MessagePack serialization with Unity (IL2CPP) support.

  • MemoryPack

    You need very fast binary serialization for save data or networking.

  • ZString

    You build strings every frame and want zero allocations.

  • GenJson

    You want fast, allocation-light, source-generated JSON in Unity or plain C#.

Networking & backend

  • Mirror

    You want a mature, community-driven multiplayer framework.

  • MagicOnion

    You want type-safe RPC between a Unity client and a C# server.

  • com.unity.netcode.gameobjects

    You want Unity's official GameObject-based multiplayer.

  • FishNet

    You want a feature-rich networking framework with prediction support.

  • PurrNet

    You are choosing a Unity networking solution and want a modern, high-level alternative to Netcode for GameObjects.

Dependency injection

  • VContainer

    You want a fast, lightweight DI container with low GC pressure.

  • Zenject

    You use Zenject. Its last push was Jan 2024; the maintained Extenject fork (below) is the one to install for new work.

  • Reflex

    You want a minimal DI container with a small API.

UI & tweening

  • UIEffect

    You want shader-based effects (shadow, gradient, dissolve, blur) on uGUI.

  • SoftMaskForUGUI

    You need soft (alpha) masks in uGUI.

  • dotween

    You want the long-standing tween library; free tier, with a paid Pro add-on.

  • PrimeTween

    You want allocation-free tweens and sequences in one line.

  • UniText

    You need a text engine that handles every language, emoji and style beyond what TextMeshPro covers.

Editor & debugging

  • Harmony

    You need to patch .NET methods at runtime, mostly for modding.

  • NaughtyAttributes

    You want inspector attributes (ShowIf, Button, Foldout) without writing editors.

  • graphy

    You want an on-screen FPS, memory and audio overlay in builds.

Official source & samples

  • UnityCsReference

    You want to read Unity's C# source for the engine and editor.

  • EntityComponentSystemSamples

    You are learning DOTS/ECS and want official samples.

  • Graphics

    You want the source and samples for URP, HDRP, Shader Graph and VFX Graph.

  • BoatAttack

    You want a URP showcase project (water, boats, race game).

  • InputSystem

    You use the new Input System and want its source and issues.

  • Unity.Mathematics

    You want Burst-friendly math types (float3, quaternion, noise).

  • SpaceshipDemo

    You want a full HDRP showcase project to read and learn from.

CI & build

  • unity-builder

    You want to build Unity projects in GitHub Actions.

AI & agents

  • unity-mcp

    You want an AI client (Claude, Cursor, etc.) to drive the Unity Editor over MCP. Most popular option.

  • Unity-MCP

    You want an MCP bridge between AI agents and the Unity Editor and runtime.

Rendering & VFX

  • StableFluids

    You want a GPU implementation of Stam's Stable Fluids.

Learning repos

  • Marching-Cubes

    You want the marching cubes algorithm in Unity.

Gameplay & AI

  • Fluid Behavior Tree

    You need behaviour trees for enemy or NPC AI with a code-first builder API.

  • UniState

    You need a scalable, async state machine for game flow, UI or characters without writing glue code.

  • MPath

    You need fast A* pathfinding on a 2D grid, in Unity or plain .NET.

  • MLock

    You need to lock and unlock gameplay elements (input, doors, abilities) through configurable tags.

C# & performance

  • OneOf

    You want F#-style discriminated unions with exhaustive matching in C#.

  • LinqGen

    You want LINQ-style queries without allocations, using code generation.

  • MGenerators

    You want Roslyn source generators to remove boilerplate around common gameplay patterns.
