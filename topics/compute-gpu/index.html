Compute shaders & GPU

Compute shaders let the GPU do general-purpose work: simulations, particles, culling, procedural meshes and image processing. These guides cover dispatching compute work, buffers, GPU instancing and indirect drawing. Worth learning once your CPU is the bottleneck for work that can run in parallel. 28 hand-picked Unity guides, tutorials, videos and repos, kept current.
