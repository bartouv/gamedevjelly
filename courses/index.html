Courses

Courses worth taking, free and paid, with the guides in the library that cover the same topics.

Getting started

  • Unity Essentials pathway

    Unity · Free. You are new to Unity and want the official, free first steps: the editor, scenes and a first project.

  • Complete C# Unity 2D Game Development

    GameDev.tv. You want a long, guided course that teaches C# and Unity 2D by building complete games.

  • Complete C# Unity 3D Game Development in Unity 6

    GameDev.tv. You want a long, guided course that teaches C# by building five complete 3D games, the natural follow-up to the 2D course.

  • Learn Unity: Beginner to Intermediate

    Code Monkey · Free. You want a free, 10-hour course that builds a full game: character controllers, events, Shader Graph, the Input System and state machines. Re-released each year.

  • The Ultimate Guide to Game Development with Unity (Official)

    Jonathan Weinberger. You want an introduction to Unity and C# made in partnership with Unity, building three games through hands-on challenges.

  • The Ultimate Unity Game Developer Course: From Zero to Hero

    Juan Gabriel Gomila. You want a very long course that builds five full games, including a Fruit Ninja clone, and prepares you for the Unity Certified Associate exam.

C# & architecture

  • Junior Programmer pathway

    Unity · Free. You know the editor and want to learn C# scripting by building small projects, for free.

  • Design Patterns for Game Programming

    Penny de Byl. You want the command, flyweight and observer patterns, ScriptableObjects and undo/replay explained with game examples.

  • Unity 6 Game Development with C# Scripting

    Packt. You want a structured, certificate-style path through Unity 6 and C# scripting, from the basics to AI, multiplayer and deployment.

  • Hands-On: C# for Beginners

    Nick Chapsas · Free. You are new to C# and want a full, exercise-based course: syntax, object-oriented programming, collections, async, file I/O and modern features up to C# 13 and 14. About 21 hours across 219 lessons.

  • Hands-On: SOLID Principles in C#

    Nick Chapsas. You know basic C# and object-oriented programming and want to apply the five SOLID principles, refactoring messy code with exercises in an in-browser editor. About 12.7 hours.

  • Hands-On: Creational Design Patterns in C#

    Nick Chapsas. You want the five creational patterns in C# (Singleton, Factory Method, Builder, Prototype and Abstract Factory), finishing with practical example projects. About 4.75 hours.

  • Hands-On: Structural Design Patterns in C#

    Nick Chapsas. You want the structural patterns in C# (Adapter, Bridge, Composite, Decorator, Facade, Flyweight and Proxy), with five applied projects. About 4 hours.

  • Hands-On: Behavioral Design Patterns in C#

    Nick Chapsas. You want the behavioral patterns in C# (Strategy, State, Observer, Command, Mediator and more), including combined examples. About 7.5 hours.

  • Hands-On: LINQ in C#

    Nick Chapsas. You want to master LINQ: the pipeline model, common operators, deferred execution, building your own operators, and parallel and async LINQ. About 9.8 hours.

Multiplayer

  • Unity 6: Multiplayer Creation

    Unity · Free. You want a short, free introduction to setting up a multiplayer scene with the Multiplayer Center and Netcode for GameObjects.

Math for games

  • Math for Game Devs

    Freya Holmér · Free. You want a complete maths course for games: vectors, dot and cross products, matrices, trigonometry, rotations, interpolation and derivatives, in 10 parts with assignments.

  • Procedural Geometry

    Freya Holmér · Free. You want to generate meshes in code, taught as an improvised live course.

Shaders & VFX

  • Shaders for Game Devs

    Freya Holmér · Free. You want a three-part introduction to shaders: basics, blending, textures, health bars, SDFs, lighting and normal maps.

  • Intro to Shader Coding in Unity

    Freya Holmér · Free. You want to start writing shader code in Unity, taught as an improvised live course.

Workflow & DevOps

  • Intro to Tool Dev in Unity

    Freya Holmér · Free. You want to build your own editor tools in Unity, in a four-part improvised live course.
