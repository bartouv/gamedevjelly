# Linden Reid

Blog of Unity shader and procedural geometry tutorials, written in ShaderLab/CG for the built-in pipeline between 2017 and 2019: toon shading, dissolves, rim light, waving grass, and an intro series on procedural meshes. The ideas carry over to URP and Shader Graph; the code does not paste in directly.

- site: https://lindenreidblog.com/
