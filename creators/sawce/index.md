# Sawce Games

Indie game development group from Brazil that publishes shader studies, such as a Skillshot Arrow shader and a Nier Automata shader study.

- site: https://sawcegames.com/
- discord: https://discord.gg/sJBADrP

- [Skillshot Arrow Shader | Sawce](https://www.sawcegames.com/en/post/skillshot-arrow-shader): Blog post on a skillshot arrow indicator shader. (Sawce Games, 2020-03-06, article, Unity-old era)
- [Nier Automata shader study | Sawce](https://sawcegames.com/en/post/nier-automata-glitch): Shader study recreating NieR:Automata's glitch effect. (Sawce Games, article)
