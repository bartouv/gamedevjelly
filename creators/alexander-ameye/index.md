# Alexander Ameye

Writes a personal blog about Unity, shaders, graphics engineering, rendering, technical art and programming, including stylized water and real-time caustics write-ups.

- site: https://ameye.dev/
- github: https://github.com/alexanderameye
- x: https://x.com/alexanderameye

- [Technical blog by Alexander Ameye.](https://ameye.dev/): Alexander Ameye's blog about Unity, shaders and graphics engineering. (Alexander Ameye, 2023-07-24, article, Unity-2022 era)
- [Stylized Water Shader](https://alexanderameye.github.io/notes/stylized-water-shader/): Step-by-step tutorial on building a stylized water shader in Unity. (Alexander Ameye, 2023-03-09, article, Unity-2022 era)
- [Rendering realtime caustics](https://alexanderameye.github.io/notes/realtime-caustics/): Tutorial with code on rendering realtime caustics in Unity using shaders. (Alexander Ameye, 2022-03-21, article, Unity-2022 era)
- [Stylized Water For URP](https://alexanderameye.github.io/stylized-water): Product page for a stylized water shader for URP. (Alexander Ameye, 2020-09-09, article, Unity-old era, URP)
- [Pixelation Shader](https://alexanderameye.github.io/pixelation): Tutorial on creating a pixelation shader. (Alexander Ameye, article)
- [Parallax Card](https://alexanderameye.github.io/parallax-card): Tutorial on building a parallax card effect. (Alexander Ameye, article)
- [Comic book (halftone) shader](https://alexanderameye.github.io/notes/halftone-shader/): Builds a comic-book halftone shader that renders the camera view like CMYK print. (Alexander Ameye, article)
- [5 ways to draw an outline](https://alexanderameye.github.io/notes/rendering-outlines/): Compares several techniques for rendering outlines and highlights, from vertex-based to screen-space. (Alexander Ameye, article)
