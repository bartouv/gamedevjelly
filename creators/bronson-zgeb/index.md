# Bronson Zgeb

Game developer, previously at Unity, KO_OP and Square Enix Montréal. Writes Unity tutorials on ScriptableObject design patterns, custom lighting in Shader Graph, SDFs and procedural generation. His blog has been quiet since 2023, but the articles hold up.

- site: https://bronsonzgeb.com/
- github: https://github.com/bzgeb
- x: https://x.com/bzgeb

- [Procedural Generation with Cellular Automata](https://bronsonzgeb.com/index.php/2022/01/30/procedural-generation-with-cellular-automata/): Generates cave-like levels in Unity with cellular automata, step by step. (Bronson Zgeb, 2022-01-30, article, Unity-2022 era)
- [Drawing with SDFs in Unity](https://bronsonzgeb.com/index.php/2022/01/15/drawing-with-sdfs-in-unity/): Draws shapes with signed distance fields in a Unity shader, from the basics. (Bronson Zgeb, 2022-01-15, article, Unity-2022 era)
- [Build a better collider importer with Asset Processors](https://bronsonzgeb.com/index.php/2021/11/27/better-collider-generation-with-asset-processors/): Uses an AssetPostprocessor to automate collider setup when models are imported. (Bronson Zgeb, 2021-11-27, article, Unity-2021 era)
- [Low Power mode in Unity](https://bronsonzgeb.com/index.php/2021/10/16/low-power-mode-in-unity/): Lowers frame rate and work when a Unity game does not need full power, saving battery. (Bronson Zgeb, 2021-10-16, article, Unity-2021 era)
- [Custom Lighting in Shader Graph Part 2](https://bronsonzgeb.com/index.php/2021/10/11/custom-lighting-in-shader-graph-part-2/): Continues the custom lighting series: adding more lighting terms in a Shader Graph. (Bronson Zgeb, 2021-10-11, article, Unity-2021 era)
- [Custom Lighting in URP with Shader Graph](https://bronsonzgeb.com/index.php/2021/10/04/custom-lighting-in-urp-with-shader-graph/): Builds custom lighting for URP inside Shader Graph using custom function nodes. (Bronson Zgeb, 2021-10-04, article, Unity-2021 era)
- [The Command pattern with Scriptable Objects](https://bronsonzgeb.com/index.php/2021/09/25/the-command-pattern-with-scriptable-objects/): Implements the Command pattern with ScriptableObjects so commands become reusable assets. (Bronson Zgeb, 2021-09-25, article, Unity-2021 era)
- [The Type Object pattern with Scriptable Objects](https://bronsonzgeb.com/index.php/2021/09/17/the-type-object-pattern-with-scriptable-objects/): Uses ScriptableObjects as the Type Object pattern to define data-driven variants. (Bronson Zgeb, 2021-09-17, article, Unity-2021 era)
- [The Scriptable Object Asset Registry Pattern](https://bronsonzgeb.com/index.php/2021/09/11/the-scriptable-object-asset-registry-pattern/): A ScriptableObject registry that finds and loads assets without scene references. (Bronson Zgeb, 2021-09-11, article, Unity-2021 era)
- [Particle Metaballs in Unity using URP and Shader Graph Part 3 – Bronson Zgeb](https://bronsonzgeb.com/index.php/2021/03/13/particle-metaballs-in-unity-using-urp-and-shader-graph-part-3/): Part three of a series on drawing particle metaballs in URP with Shader Graph. (Bronson Zgeb, 2021-03-13, article, Unity-2021 era, URP)

(Bronson Zgeb, 2021-03-06, article, Unity-2021 era, URP)
