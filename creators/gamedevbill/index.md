# GameDevBill

Programmer with over a decade in games who shares Unity learning notes, including a shader series, on a blog and YouTube channel.

- site: https://gamedevbill.com
- youtube: https://www.youtube.com/channel/UC__2zJ9MPxfA943H13K6x8g/
- x: https://x.com/gamedevbill

- [Math in Art - Game Dev Bill](https://gamedevbill.com/math-in-art/): Explains embedding math in art to make shaders cheaper. (GameDevBill, 2020-09-21, article, Unity-old era)
- [Shader Series 4 – Colors As Math](https://gamedevbill.com/shader-series-4-colors-as-math/): Explains encoding data into textures, such as normal, displacement and noise maps, for shaders. (GameDevBill, 2019-09-02, article, Unity-old era)
- [Shader Series 2 – Basic Shaders](https://gamedevbill.com/shader-series-2-basic-shaders/): Basic shader samples that teach shader concepts by example. (GameDevBill, 2019-08-05, article, Unity-old era)
- [Shader Series 1 – High Level Concepts](https://gamedevbill.com/shader-series-1-high-level-concepts/): High-level concepts to get started writing shaders. (GameDevBill, 2019-07-27, article, Unity-old era)
- [Game Dev Bill](https://gamedevbill.com/): Site with Unity game dev tutorials and tips. (GameDevBill, article)
- [@GameDevBill: profile, shaders and VR dev](https://twitter.com/gamedevbill): Bill Ramsour's X profile, a shader and VR developer. (GameDevBill, post)
