# Staggart Creations

Unity developer who publishes open-source rendering and editor utilities on GitHub, including a GPU raycaster, a MeshLOD-to-FBX exporter and a terrain layer sampler.

- github: https://github.com/staggartcreations
- site: http://staggart.xyz
- x: https://x.com/_staggart_

- [MeshLOD2Fbx](https://github.com/staggartcreations/MeshLOD2Fbx): An editor utility that exports LODs generated by Unity 6.2+'s MeshLOD system to an FBX file. (Staggart Creations, 2025-08-20, repo, Unity-6 era)
- [UnityTerrainLayerSampler](https://github.com/staggartcreations/UnityTerrainLayerSampler): Scripting functionality to efficiently read terrain layer weights, usable to drive physics, VFX and SFX. (Staggart Creations, 2022-02-16, repo, Unity-2022 era)
