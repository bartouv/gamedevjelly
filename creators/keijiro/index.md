# Keijiro Takahashi

Unity technical artist and prolific open-source author: VFX Graph and Shader Graph samples, post effects (Kino), GPU simulations, audio and video I/O plugins, and many small experiments. Based in Tokyo and long associated with Unity Japan.

- site: https://www.keijiro.tokyo
- github: https://github.com/keijiro
- x: https://twitter.com/_kzr
- youtube: https://youtube.com/denkitribe

- [GitHub - keijiro/NoiseBall6: Unity sample project: Direct mesh data access from compute shaders](https://github.com/keijiro/NoiseBall6): Repo: direct mesh data access from compute shaders in Unity. (Keijiro Takahashi, 2021-06-07, repo, Unity-2021 era)
- [GitHub - keijiro/KinoAqua: Watercolor effect for Unity URP/HDRP](https://github.com/keijiro/KinoAqua): Repo: watercolor effect for URP and HDRP. (Keijiro Takahashi, 2021-05-10, repo, Unity-2021 era, MULTI)
- [GitHub - keijiro/DofVfxSamples: DoF particle sample for Unity VFX Graph](https://github.com/keijiro/VfxBokeh): Repo: depth-of-field particle sample for VFX Graph. (Keijiro Takahashi, 2020-11-29, repo, Unity-old era)
- [GitHub - keijiro/KinoFeedback2: Old-school frame feedback effect for Unity HDRP](https://github.com/keijiro/KinoFeedback2): Repo: old-school frame feedback effect for HDRP. (Keijiro Takahashi, 2020-09-18, repo, Unity-old era, HDRP)
- [GitHub - keijiro/GeoVfx: Examples of geographical data visualization with Unity VFX Graph](https://github.com/keijiro/GeoVfx): Repo: geographic data visualization examples with VFX Graph. (Keijiro Takahashi, 2019-08-02, repo, Unity-old era)
- [GitHub - keijiro/SdfVfxSamples: Unity VFX Graph samples with SDF (signed distance field)](https://github.com/keijiro/VectorFieldExamples): Repo: VFX Graph samples using signed distance fields. (Keijiro Takahashi, 2019-07-26, repo, Unity-old era)
- [GitHub - keijiro/StableFluids: A straightforward GPU implementation of Jos Stam's "Stable Fluids" on Unity.](https://github.com/keijiro/StableFluids): Repo: GPU implementation of Jos Stam's Stable Fluids in Unity. (Keijiro Takahashi, 2018-06-27, repo, Unity-old era)
- [GitHub - keijiro/StandardTriplanar: Unity's standard shader with triplanar mapping](https://github.com/keijiro/StandardTriplanar): Repo: Unity's standard shader extended with triplanar mapping. (Keijiro Takahashi, 2015-05-26, repo, Unity-old era, BUILTIN)
