# Moonjump

Independent game studio in Canberra, Australia. Publishes the Mechanics Library: long-form, interactive tutorials on how game systems work, from pathfinding and procedural generation to rendering and physics.

- site: https://moonjump.com/
- x: https://x.com/moonjumpstudios

- [Screen Space Ambient Occlusion (SSAO): how it works](https://moonjump.com/game-dev-mechanics-screen-space-ambient-occlusion-ssao-how-it-works/): Covers the SSAO algorithm from the AO integral and depth sampling through hemisphere kernels and noise rotation. (Moonjump, 2026-03-08, article, Unity-6 era)
- [Skeletal Animation & Skinning: how it works](https://moonjump.com/game-dev-mechanics-skeletal-animation-skinning-how-it-works/): Explains bone hierarchies, inverse bind matrices, and linear blend skinning that deform meshes into animated characters. (Moonjump, 2026-03-05, article, Unity-6 era)
- [Third-Person Camera Systems: how it works](https://moonjump.com/game-dev-mechanics-third-person-camera-systems-how-it-works/): Shows follow cameras, exponential damping, and raycast-based collision avoidance for third-person cameras. (Moonjump, 2026-03-01, article, Unity-6 era)
- [Navigation Meshes (NavMesh): how it works](https://moonjump.com/game-dev-mechanics-navigation-meshes-navmesh-how-it-works/): Explains how navmeshes decompose walkable space into convex polygons, from Recast generation to the funnel algorithm. (Moonjump, 2026-02-26, article, Unity-6 era)
- [Procedural Dungeon Generation: how it works](https://moonjump.com/game-dev-mechanics-procedural-dungeon-generation-how-it-works/): Shows how Binary Space Partitioning trees generate roguelike dungeon layouts, with an interactive demo. (Moonjump, 2026-02-22, article, Unity-6 era)
